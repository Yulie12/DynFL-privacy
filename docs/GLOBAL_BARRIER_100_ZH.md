# 100%全局同步流程

用户确认：先跑通100%准入，90%仅留作后续对照。本次不启动正式实验矩阵，
也不改变CIFAR-10冻结分类头设置；全参数训练另行处理。

## 执行语义

1. 本轮选模后固定更新单元集合：每个非空(Edge,模式)组一个单元，每个FL_C客户端一个单元。
2. 三种模式全部从同一个已广播确认的Cloud版本开始训练；FL_EC保留轮内多阶段反馈。
3. FL_E局部Edge返回完成可结束局部链路，但其Cloud上传必须计入100%准入。
4. 全部本轮单元到达后Cloud聚合。没有周期时钟、迟到队列或跨轮接受。
5. Cloud广播至所有配置客户端，包括本轮SKIP客户端；客户端收到并安装模型后回ACK。
6. 同版本ACK收齐且逻辑时间达到最后ACK时刻后，训练循环才允许下一轮执行。
7. 全SKIP不产生新Cloud版本；仍同步确认现有版本，不伪造历史观测或DP步骤。

当前假设所有客户端最终可达。ACK默认64字节，安装耗时默认1ms；与训练/通信时延一样
属于可配置模型参数，不是物理网络实测。Edge模式采用Cloud→Edge→客户端及反向ACK，
FL_C/SKIP采用直接Cloud路径。各客户端路径独立计算，不模拟链路争用或组播复用。

## 安全边界

- `cloud_quorum=.9`会明确报错，未定义取消/丢弃语义前不可启用。
- 下一轮任何模式都不得使用旧Edge独立副本，增量以本轮Cloud版本为共同基准。
- 缺失ACK阻止下一轮，即使Python主机已顺序执行完本轮训练。
- DP按真实执行步骤累计，不因模型屏障重置隐私账本。
- 模拟ACK不是远程设备真实ACK；当前没有网络服务或物理分布式运行。
