# 正式实验启动准备：shared_init_v1

本轮只准备和验证，不启动正式矩阵，不推送，不改论文数学定义。

## 锁定方法与初始化

核心三臂为`latency_only`、`joint_no_ema`、`proposed`。后两者共用同一J公式、Pareto搜索、
归一化Chebyshev选择；无EMA臂有效配置为gamma_d=0、gamma_C=.9，完整臂为.9/.9。
单独优化J的deviation_only已从活动策略及主配置移除，不冒充无EMA联合方法。

正式名单逐项理由：

| 策略 | 所回答的问题 |
|---|---|
| latency_only | 仅T选择基线 |
| joint_no_ema | 加入J、但不平滑模式偏差的作用 |
| proposed | 在T+J基础上增加偏差EMA的作用 |
| fixed_fl_e | 固定Edge路径的系统时延与学习基线 |
| fixed_fl_ec | 固定多阶段Edge-Cloud路径，显式记录更多本地训练步骤 |
| fixed_fl_c | 固定直达Cloud路径 |
| fixed_mixed | 预先固定的混合分布，不进行动态搜索 |
| random_feasible | 在相同可行性/选模周期规则下随机选模 |

仍为8项是独立研究问题审核的结果，不是保留旧8项：joint_no_ema替换deviation_only。
固定FL_E和FL_C在共同起点、相同本地步骤及样本加权的理想条件下可有等价的全局更新；
保留二者是区分聚合/传输路径的系统基线，不能把浮点级精度差包装成学习收益。
后三类固定/随机基线不参与核心三臂的冷启动因果消融；固定策略始终保持其命名模式。

核心三臂使用两轮共享初始化（计入总100轮，不额外增加训练）：

1. 轮1固定客户端i使用MODES[i mod 3]，执行真实训练，建立Cloud历史参考。
2. 轮2重复该分布，执行真实训练，首次建立三种模式的有效偏差观测。
3. 轮3开始各臂独立搜索；保持全局选模周期规则，初始化结束强制首次搜索。

至少3个客户端且总轮数大于2。资源/隐私约束不能执行预定分布时明确报错，不以零补缺失、
不自动延长初始化预算。两轮是当前“第一轮只能建立参考”的数学定义下的最小有效方案。
共同输入下三臂的两轮模型、模式偏差、全局参考和隐私账本必须一致；之后轨迹允许分叉。
初始化步骤、epsilon、系统时间、阶段结束准确率单独记录，并同时包含在端到端成本中。

## 候选公平性与证据

不改变论文自适应邻域搜索以强行共享候选：同一状态下使用相同确定性种子分布、可行规则、
邻域、评价预算和归档预算。相同历史输入时，两种联合策略的候选和选择一致（回归测试）。
不同目标影响扩展方向，后续模型/账本/上一分布也会不同，不能声称实际候选集合总相同。
保存每轮全部已评价候选的profile、T、J、模式样本质量、归档、可行池、选中profile以及
执行前冻结历史。可以独立复算选择，并检查候选集合交集；不能据此声称穷举全局最优。
T-only也记录J供审计，但不使用J排序或选择。测量的搜索耗时包含共同诊断计算，
不是无日志的生产环境最低开销；模型T不包含搜索/文件I/O开销，主机实际时间另报。

## 恢复与故障安全

- 每轮完成且全部ACK后保存不可覆盖的轮级检查点及SHA256，包含完整模型参数、历史、
  各客户端RDP账本、Cloud/客户端版本、屏障、上一分布、阶段、时间线控制状态、累计日志、
  Python/NumPy/Torch/CUDA随机状态。
- 本地优化器是显式无动量SGD，不存在跨块动量；检查点明确记录该事实，不伪造优化器状态。
- 每个DP步骤原子保存局部模型、随机采样/噪声生成器状态、完成步数和账本；完成块保存
  输出和输入身份（种子、sigma、起始账本、起始模型哈希）。恢复时复用已完成块，
  部分块从最后持久化步继续，不重做已提交步骤，也不把账本重置为零。
- 如果实际账本已前进但持久化事务没有覆盖，写unsafe_privacy_state并拒绝自动恢复；
  保留证据，不能默默回滚。崩溃时尚未持久化、未对外发布的计算不能声称物理上绝不重算。
- 已完成运行的resume不改写结果；配置、源码、数据、划分或轨迹不匹配时拒绝恢复。
- 训练异常/中断记录失败原因和尝试时间；不产生完整summary，不放行下一轮。
- 更新接收在模型改变前校验100%完整集合、重复/外来/迟到单元及Cloud版本。
- 缺失ACK不放行，100%协议不自动降为90%；当前逻辑网络仍假设最终可达，不实现物理重连。
- 同一输出目录必须顺序使用，不能并发启动多个resume进程；当前驱动器顺序执行。

## 审计与预登记

未预登记的100客户端100轮场景拒绝启动。预登记命令不启动训练。

独立审计从本地块结果重建每轮Edge/Cloud更新、样本权重、模式历史、RDP累计与观测J；
从候选日志重算T/J及联合选择，核查全部ACK和下一轮时刻。统计入口实时审计，不信任
残留audit.json或仅有summary文件；完整必需运行缺失或审计失败则拒绝统计。
初步验证记录和最终实测数据随后追加；不得将本说明当作正式实验已完成。
